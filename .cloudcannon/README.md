# Sendit website

The marketing website for Sendit: the home page, product pages, a blog, and the site-wide navigation, footer and search settings.

## Pages

Every page on the site, including the home page, the 404 page and the blog's intro. Most pages are built from sections: open a page in the Visual Editor, then add, remove, reorder or edit its sections. Each section's fields are also in the sidebar.

To create a page, click **+ Add** and choose **Page**. Until the site rebuilds, a new page previews on the About page; it shows its own sections after the next build.

The **Blog** page holds the blog's heading, intro text and how many posts show per page. It has no sections.

## Blog

Blog posts open in the Visual Editor; switch to the Content Editor to write longer text. New posts open in the Content Editor. Each post has a title, date, author, tags, a thumbnail for the blog listing and a featured image for the post page.

In the post text, use the **Snippet** button to insert:

- **Button**: a link styled as a button
- **Embed**: an embedded web page, such as a video

## Site settings

- **blog**: the "Recent Blog" heading and the reading-time and word-count labels on each post
- **footer**: the footer logo, copyright line, social links and link columns
- **nav**: the top navigation logo, links and button
- **site**: the site title, default description, sharing image and icons used by search engines and social sites
- **theme**: the site's colours
- **tags**: the tags available on blog posts. Add a tag here before using it on a post

Changes to the theme colours show after the site rebuilds.
