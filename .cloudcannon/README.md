# Sendit

The Sendit marketing website: its pages, blog posts and the navigation and footer shared by every page.

## Quick links

- [Pages](cloudcannon:collections/pages)
- [Blog](cloudcannon:collections/blog)
- [Site data](cloudcannon:collections/data)

## Pages

Each page is built from sections you can add, remove and reorder. Open a page in the Visual Editor, click any heading, paragraph, button label or image to change it, and use the section controls to move, duplicate or delete a section. **Add** between sections opens the list of section types.

New pages start empty. Until the site rebuilds, a new page previews the About page.

## Blog

Blog posts open in the Visual Editor. Click the title, author, featured image or body to edit them. The body supports Button and Iframe components from the toolbar. The publish date is set in the sidebar and shows on the page after the next build.

The Blog page itself (title and intro) is in Pages, as "blog".

## Site data

- **nav** — the logo, menu links and the button in the header.
- **footer** — the footer logo, copyright text, social links and link columns.
- **blog** — the "Recent Blog" heading and the reading time and word count labels on each post.
- **site** — the site name, description and sharing image used by search engines and social media.
- **theme** — the site colours.

You can also edit the header and footer directly on any page in the Visual Editor.
